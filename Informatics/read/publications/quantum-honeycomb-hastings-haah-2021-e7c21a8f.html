Dynamically Generated Logical Qubits

Matthew B. Hastings; Jeongwan Haah · Quantum · 2021 · Theoretical quantum error-correcting code

Original publication · Original publication

Recorded summary

Hastings and Haah construct a honeycomb code in which a repeating schedule of two-qubit measurements creates logical qubits. Information protection comes from the code and measurement sequence acting together on the lattice.

Recorded limitations

The paper does not show that a passive hexagon alone protects information. Implementing this code requires the specified measurements and decoding; the current Aquila workflow does not implement that procedure.
